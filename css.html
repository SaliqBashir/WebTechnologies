B5 — Custom Properties

CSS Variables

Declared with --name on :root, consumed with var(--name). Scope can be overridden locally.

Ocean Theme

Local --t-accent, --t-bg, --t-text override the global palette without touching any other element.

  • --t-accent: #38bdf8
  • --t-bg: #0c1e35

Forest Theme

Same HTML structure, same CSS class pattern — only the custom property values differ. No duplication.

  • --t-accent: #4ade80
